# Bestiario Urbano · Bogotá Arcade

Juego educativo en el navegador: recorre Bogotá y **calma** a seis animales urbanos enojados (copetón, gata, paloma, perro criollo, rata y oso andino) usando acciones reales de manejo de fauna. Aquí no se gana derrotando: se gana entendiendo la causa del problema, que casi siempre es humana.

## Jugar

Ábrelo en el navegador desde la página de GitHub Pages de este repositorio. Funciona en computador, tableta y celular.

- **Moverse:** flechas, WASD o mantener pulsado/tocado sobre el mapa.
- **Interactuar / avanzar:** Enter, Espacio o clic.
- **Música:** botón 🔊 o tecla M.

## Créditos

- Diseño del juego y personaje: Diego Peña.
- Mapa ilustrado: Sr. Nadie Me Busca.
- Contenido basado en el documento «Bestiario urbano de Bogotá — perfiles de personajes».
